# Review rules

Use only the answer form supplied in the complete issued card. Code owns IDs,
timestamps, citations, hashes, exact quotations, versions and receipt schemas.
No new JSON fields or pseudocommands are specified here.

## Sources and personnel

For a baseline, state supported current information without inventing historical
change. For a comparison, use the supplied before/after evidence. A navigation page,
missing body or inaccessible attachment cannot establish unchanged substantive law.
Unknown technical changes remain explicit; do not explain them as harmless scripts
without evidence. A document's new link does not establish a new adoption date.

Select a supplied existing-person reference when supported. A successor is a new
person, not a rename. Name similarity alone cannot merge identities or transfer
contacts. Preserve conflicts and distinguish county, circuit and actual assignment;
a circuit-wide footer does not assign every judge to every county.

Report supported contact, role, assignment, procedure links and basic operating
changes. Staff such as bailiffs and law clerks belong in the judge's staff fields
even if not separate directory entities. Noncivil assignment does not exclude
those facts. Omit career biography and unrelated specialized merits research.

Copy structured values from supplied evidence/links as required by the existing
validator; preserve address line breaks and actual phone/email values. Put practical
paraphrases in the summary. For new people include supported current contacts;
never inherit a predecessor's personal contact. Code preserves other saved fields.
Absence from one page does not authorize removal or establish departure.

## Opinions

Use the supplied relevance, summary, holding, disposition, authors and evidence
fields. The holding states the operative rule and facts with exceptions and record
limits. The practical summary must retain the same material qualifications. The
disposition states what the court did. Authors are byline names, not panel members.
Do not publish internal metadata reconciliation in these fields.

Preserve assumed versus decided issues, plurality/lead reasoning versus panel
holding, substituted or withdrawn status, and limits on present-record relief.
“Ordinarily” is not “always”; an example is not an exclusive test. If supplied
evidence identifies a conflict with current practice, preserve or flag it through
the bounded exception route; do not invent a controlling rule or start an unrelated
legal research project.

Civil/appellate procedure is relevant even without a novel rule and includes
individual/small-claims parties. A complete unexplained PCA may be excluded briefly
with an empty holding. A citation affirmance stating applicable principles is not
a bare PCA. Missing evidence remains unresolved. Do not infer nonprecedential
status from “per curiam,” citation format or absence of a reporter cite.

## Recovery decisions

First rejected answer: fix the named issue, retain correct content. Identical retry
recovers the exact outcome rather than consuming a new attempt. After the existing
distinct-rejection limit, retain the unresolved checkpoint and continue only as
directed by code. Do not write maintenance receipts, inspect internal code, strip
all contacts, or certify no-change to clear an error.

Use existing evidence first. Additional retrieval must resolve an identified
material gap in this task. Record unknown dates, inaccessible sources and genuine
conflicts honestly; do not resolve them by speculation or exhaustive research.
