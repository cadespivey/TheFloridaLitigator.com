# Current review integrity rules

After launcher preflight, read `docs/workflow/REVIEW_INTEGRITY.md` in the verified
checkout identified by `installation.json`/preflight. That repository document is
the authoritative contract for v6 aligned reviews, content availability,
withdrawals, explicit correction commands and evidence-bound repair checkpoints.
Keep using that same pinned checkout; do not search another worktree for a more
permissive template or copy old instructions from a prior transcript.
