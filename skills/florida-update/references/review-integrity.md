# Integrity and maintenance lookup

Current live-comparison corrections: execute the returned checked helper command,
not the underlying raw workflow answer CLI. At an authorized stopping point copy
returned handoff_text; it is not a stop signal and does not replace downstream
approval/publication. Do not inspect task/log directories or reconstruct counts.
Opinion cards include the complete short guidance: general civil/appellate matters
remain in scope without a novel-rule or case-specific-application requirement;
citation affirmances stating applicable civil principles can be relevant; complete bare PCAs need no
underlying-case research; missing evidence stays pending. Do not infer publication
status, drop express legal exceptions or add source bookkeeping to summaries.


Routine source/opinion review uses one complete inline review_card and a JSON
answer on stdin to its returned review HANDLE command. Code saves the original
input and returns the complete next card; no separate file reading/writing.
Identical invalid retries reuse their error without another failure attempt;
changed accepted replies require explicit correction. Do not load extra manuals, manifests or full receipts for a normal task.
Code owns acquired quotation/provenance copying, exact versions and receipt checks.
New-person records include current contacts explicitly supported in the card even
if unchanged on the page. Preserve factual text and useful address line breaks; code tolerates formatting whitespace in supported contact fields only. Quotes, URLs/emails, digits and punctuation remain exact.
Never invent contacts or transfer a predecessor's personal details.
When an error names a person/field, repair that field and keep other supported
contacts. Do not inspect code/raw packets or write diagnostic scripts for this.

Short-answer errors are saved by code. After two rejected answers a source-bound
unresolved checkpoint permits other ordinary work. At review_exceptions preserve
the pending state and exact cause; it is not a completed update or permission to
advance the finalized baseline. Do not repair quotation whitespace yourself or
attribute errors to a helper without evidence. Corrected answers may pass later.

For explicit maintenance/correction, use the returned maintenance-task or exact
predecessor-bound revise command. Read repository docs/workflow/REVIEW_INTEGRITY.md
for the specific correction. Compatible v7 raw-group/quote interfaces are for
that maintenance task only. Unknown script/nontext evidence never becomes benign
from an empty text diff, hostname or plugin name. Preserve originals and accepted
history. Full submit/revise retains its legacy two-failure repair-note gate;
that gate does not apply to short answers.
