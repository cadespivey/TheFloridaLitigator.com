# Current review integrity rules

After launcher preflight, read `docs/workflow/REVIEW_INTEGRITY.md` in the verified
checkout identified by `installation.json`/preflight. That repository document is
the authoritative contract for v7 bounded evidence reviews, content availability,
withdrawals, explicit correction commands and evidence-bound repair checkpoints.
Keep using that same pinned checkout; do not search another worktree for a more
permissive template or copy old instructions from a prior transcript.

Read `docs/workflow/SMALL_REVIEW_PACKETS.md` for bounded group/field fragments,
exact quote selection, typed new judge/clerk drafts and full existing-person
templates. Reading aids and templates do not certify inspection or legal effect.
Follow all index `next` pointers for a selected group; keep its unresolved state
until all required fields/limits have been inspected. Preserve actual failed
draft/command counts in the run summary, including repaired failures.
