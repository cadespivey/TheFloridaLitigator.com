## Exact source and persistence lookup

The “Person sources” JSON below is the public, reviewed source index for each county. Match a stable person `id`; begin with `profile_url` and `procedure_url`. Inspect `sources` for supporting official URLs and `source_observation` for the saved evidence binding. The top-level `stream` identifies the cumulative database stream; `through_capture` pins the published observation, not necessarily its latest research. Read newer captures before writing. The county map identifies shared source acquisition paths and practical review instructions. Do not use a stale run state as the current assignment.

For each new update, identify the missing or changed required field, reuse the saved source, refresh the relevant official page/document, finish and save one person, and verify persistence before moving on. Follow [the county workflow](../../workflow/COUNTY_WORKFLOW.md) for receipt fields and bounded checklists, [checkpoint save](../../workflow/BASELINE_CAPTURE.md) for exact paths/format, and [publication](../../workflow/COUNTY_DIRECTORY_PUBLICATION.md) for reviewed public projection. Publish contacts separately from finalized weekly reports. Final integration checks current data/publication and future comparisons, without historical-report checks.
